# EyeRest — 护眼休息工具

macOS 菜单栏常驻工具。设定工作和休息时间后，每过一个工作周期自动将全屏变黑，显示休息倒计时，倒计时结束后自动恢复，循环往复，强制眼睛规律休息。

## 特性

- 菜单栏驻留，无 Dock 图标，存在感极低
- 全屏黑色遮罩覆盖所有显示器、菜单栏、Dock
- 工作和休息时长均支持秒级无极调节
- 时间设置自动记忆（UserDefaults）
- 支持开机自启
- 资源占用极低（约 15MB 内存）

## 安装和运行

### 前置条件

- macOS 13 以上
- Xcode Command Line Tools（`xcode-select --install`）

### 构建
```bash
cd eye-rest
chmod +x build.sh
./build.sh
```
构建完成后双击 `EyeRest.app` 即可运行。可拖入 `/Applications` 长期使用。

## 使用
1. 点击菜单栏圆形图标，弹出设置面板
2. 调整工作时长和休息时长
3. 打开「启用」开关
4. 需要开机自启则打开「开机自启」开关

菜单栏图标含义：
- 空心圆 ○ — 未启用
- 实心圆 ● — 工作中
- 小圆点 · — 休息中
